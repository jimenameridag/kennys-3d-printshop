# Kenny's 3D PrintShop

Página informativa para el emprendimiento Kenny's 3D PrintShop.

## Archivos
- `index.html`: estructura de la página.
- `css/styles.css`: diseño y colores.
- `js/script.js`: menú móvil y enlace de WhatsApp.
- `img/logo.png`: logo generado.

## Pendientes
1. Reemplazar los espacios de la galería por fotografías reales.
2. Colocar el número de WhatsApp en `js/script.js`.
3. Opcional: agregar ubicación, redes sociales y precios.

## Publicación
Esta página es estática y puede publicarse gratuitamente en GitHub Pages, Netlify o Vercel.
